# Archival source document

`Studiq_Dokument_Testera_v1.3.docx` (Dokument testera v1.3, 2026-10-17) is the test
document the corpus was originally seeded from. It is kept as an **archival original**
for provenance: what the test plan said at that point, in the form it was written.

**Do not regenerate `../cases/` from it.** The cases are maintained by hand in this
repository and have moved ahead of the document wherever the product changed (routes,
labels, plans, entitlements). There is no converter step in this repository, and no
tooling is expected to rewrite `cases/` from this file.
